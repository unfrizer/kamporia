# Кампория: сверка с конкурсным заданием

12 ноября 2026. Приложение v15. Проверен актуальный текст «Цифровой деканат будущего», который участник скопировал из личного кабинета конкурса. Он совпадает по существенным требованиям с исходным 2.txt.

Вывод: функциональных противоречий между проектом и заданием не обнаружено. Обязательное ядро реализовано. Дополнительные кабинеты сотрудников, клубы, ДЗ, материалы и чередующиеся недели разрешены как собственные идеи. Готовность приложения и завершённая подача — разные этапы: регистрация команды, окончательное видео и отправка ещё требуют действий участников.

Прототип: https://kamporia.ru

Исходники: https://github.com/unfrizer/kamporia

## Основания проверки

- Актуальное задание: текст участника из личного кабинета, получен 12 ноября. Пароль и личный кабинет организатора не использовались для проверки этого текста.
- [Официальный регламент](https://challenge.mgimo.ai/rules), редакция от 22 октября 2026, и [FAQ конкурса](https://challenge.mgimo.ai/): извлечены веб-сервисом. В одном запросе сервис вернул архив 2025 года; для выводов использовано повторное извлечение именно сезона 2026. Прямой HTTP-запрос независимо подтвердить не удалось. Перед отправкой следует сверить срок, показанный в личном кабинете.
- Исходный код, результаты изолированных HTTP-проверок v14, проверки загрузки и DOM v15, отчёт установки и сверка публичных файлов.
- Это проверка конкурсного прототипа; независимый аудит безопасности и массовый нагрузочный тест не проводились.

## Данные, безопасность и оформление

| Требование | Что проверено | Граница подтверждения |
| --- | --- | --- |
| Каждый студент видит свои данные | Два студента разных групп; серверные проверки владельца, группы, дисциплины и клуба; обращения к чужим идентификаторам включены в ролевые тесты | Мини-карточка содержит только разрешённые сведения сообщества; чужие оценки и заявки не доступны |
| Пароли не в открытом виде | PBKDF2-SHA-256, индивидуальные соли, серверная проверка; сессии с HttpOnly/Secure/SameSite cookie, в базе хэш токена | Демо-пароли намеренно опубликованы для жюри и относятся только к вымышленным аккаунтам |
| Ключи сервисов не в коде/браузере | Рабочая база, SSH-ключи и файлы окружения исключены из исходного комплекта | Проверка исходников, не независимый пентест |
| Только вымышленные учебные данные | Демонстрационные студенты, преподаватели, группы, оценки и заявления; реальный вуз не подключён | Имена авторов в описании команды не используются как учебные записи |
| Понятно, что это концепт | Подпись на странице входа и внутри кабинета | Не позиционируется официальным сервисом |
| Без официального логотипа вуза | Собственный знак «Кампории» | Логотип НИУ МГСУ не используется |
| Разрешённые сторонние материалы | Уведомления Lucide/Feather сохранены в исходниках и комментарии JS; системный шрифт без раздачи файлов; графика и скриншоты собственного прототипа | Перечень и источники — в дополнении о материалах |
| Адекватный стек | Один сервер, API, SQLite, переносимая Worker-сборка, разделённые модули | Для существенно большей нагрузки потребуется измерение и развитие инфраструктуры; не заявляется готовность к масштабу реального вуза |
| Доступность из России без VPN | Российский VPS; участник ранее подтвердил успешный вход без VPN; внешний пароль снят; HTTPS и четыре роли проверены | Все сети России не проверены; текущие проверки ассистента не доказывают прямой маршрут пользователя |
| Работа до 28 ноября | Развёрнуто на постоянном сервере | Будущую доступность нельзя подтвердить заранее: участникам нужно сохранить сервер и оплату до итогов |

Обновление v15 сохраняет саму боковую панель и её прокрутку при переходах и загрузке данных. Переходы занимают 120–200 мс без ожидания перед действием; системный reduced motion отключает программные анимации. Пройдены 21 проверка DOM и 15 проверок кэша/навигации. Новая визуальная проверка в браузере не выполнена: инструмент Computer Use остановил работу из-за невозможности надёжно определить адрес окна. Проверки DOM не заменяют проверку внешнего вида.

После установки пройдены 132 проверки четырёх ролей. Сверены 35 таблиц, исключая изменяемые сессии и служебное состояние, и 9 вложений; учебные данные сохранены. API не менялся: результаты 1054 изолированных HTTP-проверок v14 остаются историей проверки той же серверной логики, а не новым запуском v15.

## Условия участия, которые нельзя подтвердить кодом

Официальное название — «MGIMO AI Challenge — 2-й межвузовский промпт-хакатон». Регламент допускает команды до трёх человек. У вас заявлены два автора из НИУ МГСУ; регистрацию, статус студентов и добавление напарника капитаном ассистент не подтверждал. По опубликованному регламенту приём завершается **22 ноября 2026, 23:59 МСК**, итоги — **28 ноября**. Капитан может заменить работу до дедлайна. [Источник: разделы 2, 4, 5](https://challenge.mgimo.ai/rules).

Существенное условие: разделы 6.2–6.4 предусматривают при отправке безвозмездное отчуждение исключительных прав организатору на передаваемые материалы, с возможностью коммерческого использования. Перед отправкой прочитайте этот раздел вместе с напарником; работа автоматически не отправлялась. [Официальный текст](https://challenge.mgimo.ai/rules).

## Финальный ручной проход

1. С физического телефона без VPN: войти каждым из двух студентов, открыть день и неделю, оценки, отправить свою заявку, проверить её статус и уведомления. Проверить расположение элементов и отсутствие скачка бокового меню.
2. Открыть ссылки на сайт, репозиторий и документы с другого устройства; сверить демо-пароли.
3. Проверить состав команды, окончательное название, баланс и сохранение сервера до итогов.
4. Записать голос и фрагменты на камеру, собрать окончательное видео до пяти минут и загрузить на Яндекс Диск, Google Диск, VK Видео, RuTube или YouTube.
5. Капитану проверить условия передачи прав и отправить последнюю версию комплекта через «Моя работа» до срока в ЛК.

Прогноз баллов или победы не делается: четыре критерия оценивает жюри. Самые сильные доказательства проекта — законченные сценарии, проверка разграничения данных, реальные исправления по обратной связи и прозрачное описание работы с ИИ.
