# Как подготовлена видеодемонстрация

12 ноября 2026. Материал дополняет основной отчёт о создании приложения v14.

Для съёмки запущена отдельная локальная копия того же приложения с собственной SQLite и вымышленными данными. Через Browser / Computer Use выполнены входы студента, преподавателя и администрации, отправка заявки, ответ сотрудника, изменение аудитории, настройка недель, выбор групп и открытие клубных разделов. Для телефона использована браузерная эмуляция 390 × 844. Снимки сохранены из реально открытых экранов.

Сценарий, монтажный план, тексты, временная разметка и код подготовлены с помощью ассистента Codex. Программный монтаж выполнен Python, Pillow и NumPy: фирменная графика, появления карточек, увеличения, переходы, рамка телефона без наложенного курсора и сигналов кликов. В первой версии графический курсор не всегда точно совпадал с действиями; по замечанию автора он полностью удалён, монтаж сцен сохранён. Для кириллицы использован установленный в Windows шрифт Segoe UI. Экспорт и вшивание субтитров выполнены FFmpeg, кодек H.264.

Подготовлены две версии одной основной части продолжительностью 3 минуты 50 секунд: чистая и с субтитрами-подсказками. В отдельном SRT сохранены редактируемые временные метки. Короткие монтажные заголовки есть в обеих версиях. Сценарий содержит приветствие и финал для Никиты Быкова и Тимофея Анисимова, представляющих НИУ МГСУ; название команды shh можно заменить перед записью.

Голос и фрагменты лица автора предназначены для самостоятельной записи. В подготовленные MP4 они не добавлены. Музыка не использована. С приветствием на 18–22 секунды и финалом на 14–18 секунд общая длительность составит примерно 4:22–4:30.

При проверке каждый итоговый MP4 полностью декодирован: 6900 кадров, 1920 × 1080, 30 кадров/с, ровно 230 секунд. Текст SRT сопоставлен с полным текстом речи; проверены границы таймкодов, наличие титров в видео и композиции ключевых сцен. Результаты находятся в verification.json.

После съёмки временный сервер остановлен, база съёмки удалена. Сохранены кадры и материалы монтажа. Рабочий сайт не использовался для постановочных изменений; после съёмки он прошёл отдельную проверку 132 сценариев четырёх ролей. Публикация конкурсного видео и запись авторского голоса остаются ручными этапами.
