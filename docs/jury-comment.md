Я создал «Кампорию» - конкурсный прототип цифрового деканата, в котором расписание, успеваемость, домашние задания, материалы, заявки и общение с университетом собраны в одном кабинете. Для студента, преподавателя и администрации предусмотрены разные возможности. Интерфейс работает на телефоне и компьютере, поддерживает светлую и тёмную темы и выбор акцентного цвета.

Разработку вёл с помощью Codex Desktop: ИИ-ассистент и субагенты помогали разбирать ТЗ, писать код, проверять права, исправлять ошибки и готовить документацию. Sites использовался для первой публикации и резервной версии; основной сайт перенесён на Selectel с собственным доменом и HTTPS. В работе применялись JavaScript, HTML, CSS, Node.js, SQLite, Git и GitHub; для проверки интерфейса - Browser/Computer Use, для отчёта - Python и инструменты PDF. Видеодемонстрация подготовлена программным монтажом Python, Pillow, NumPy и FFmpeg; голос и фрагменты на камеру я записываю самостоятельно.

Я формулировал требования, выбирал решения, проверял доступность из своей сети и давал обратную связь по интерфейсу. В процессе доработаны чередующиеся недели, общие пары нескольких групп, изменения только своего расписания преподавателем и уведомления всем затронутым участникам. Для серверной логики v14 пройдены 1054 HTTP-проверки на отдельной копии. После обновления навигации v15 пройдены 21 проверка DOM, 15 клиентских проверок и 132 проверки опубликованного сайта.

Главным считаю законченные сценарии: студент не просто отправляет заявку, а получает статус и ответ; перенос пары доходит до участников; личные данные разграничиваются на сервере. Все учебные данные вымышлены, проект не является официальным сервисом вуза. Реальные этапы, промпты, инструменты и скриншоты приведены в отчёте.
